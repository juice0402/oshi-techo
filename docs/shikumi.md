## 推しキャラ

- 推しキャラのボタン（characters.json の oshi）と、公式の最新情報のページ /koushiki/（characters.json の official）
- 推しキャラは { name, slug, full, match, strict }。slug があるキャラは、fetch.mjs が「作品名＋推しキャラ名」でも楽天市場を探し（標準の並び・買えるものだけ・settings.oshiPages ページ）、商品名に名前が入っているグッズが6件以上あれば /{作品}/{slug}/ のページを作る。full はページの名前に使う呼び方（「ちいかわ うさぎ」のように、名前だけだと別のものと紛れるとき）。match はほかの書き方。strict は前後がカタカナ・英字のときは数えない（「ベル」と「ラベル」）。推しキャラの名前で探して見つかったグッズ（via: oshi）は、作品の新着には出さない
- 推しキャラのボタンは、ページがあればそのページへ、なければ「探す」へ
- わたしの推し（2026-10-23）：推しキャラのページの「わたしの推し」ボタンで選ぶ（3人まで。4人目で古い順に外れる。ボタンは点線の角丸の四角が、押すとファビコン（しましまのタイル）になる形。はじめは点線の丸と「推」のはんこで、しょーくんが2案から選んだ）。トップの特集の目次のすぐ下に「わたしの推し」が出て、ブラウザがその推しキャラのページ（このサイトの静的なページ）を読んで最初の8件を棚に入れ、「前に見てから◯件」（前にこのサイトを見たあとに初めて見つけた数。30分あいたら前の時刻を進める。30日より前は数えない）を出す。保存は見ている端末のブラウザの localStorage（ot-my・ot-cur・ot-prev）だけで、サイトや楽天には送らない。ブラウザの保存が使えないときはボタンを出さない。ホーム画面に追加（manifest）は、ホーム画面から開いたときに楽天の成果がつくか確かめられないので見送り

- 推し×種類のしおり（2026-10-23）：推しキャラのページの見出しのすぐ下に、商品が3件以上ある種類（2つ以上のとき）。えらぶと、最初の8件と一覧からその種類を全部、最初の一覧に出す（一覧はかくす。URL は #種類 だけで増やさない。えらんだものはペンの丸）。わたしの推しにしている推しキャラなら、えらんだ種類を覚えて（ot-my の c・cn）、次にひらいたときもその種類、トップの「わたしの推し」も「ハチワレ・ぬいぐるみ」のようにその種類だけ。動きは src/my.js（build.mjs がコメントを外してページに入れる）
