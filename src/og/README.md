# SNSで共有したときの画像（src/og.png）の元

og.html を 1200×630 で画面写真にしたものが src/og.png。作品名はコーナーをまたいで7つ＋「などのグッズ」なので、作品を足しても作り直さなくてよい（外した作品が入っていたら直す）。

- 2026-10-28：案A「しましま表紙の手帳」に合わせて作り直した。3案（A しましまの帯・B 手帳の表紙・C 手帳の絵つき）から、しょーくんが B。全面しましまの表紙（ピンクとラベンダー）にベリー色のゴムバンド、まん中に白いラベル（ロゴと同じふちと内側の線）、サイト名・テープの線・作品名2行
- サイト名は sitename.svg（src/icons/logo.svg の字の形だけを切り出したもの。字のデータは読みこまない）。作品名の字は Noto Sans CJK JP の太字（字のファイルはリポジトリに入れない）
- 写し方：Noto Sans CJK JP が入っている所で、Python の Playwright で viewport 1200×630（倍率2で写して 1200×630 に縮める）。この作業場所には字が入っている。256色にしても字はきれい（約40KB）
- この作業場所で写せないときは、GitHub Actions の「SNSの画像を作る」（.github/workflows/og.yml）を作業ブランチで手で動かすと、og.html と variants/ の案を写して src/og/renders/ にコミットする。よいものを src/og.png に置きかえ、renders/ は消してからマージする
- これまで：10/26 ファビコンのタイルとおそろい（e-candy・手書きふうの字）、10/27 作品名の案 B
