# 入荷ビンゴの絵

- nui・acsta・badge・key・pouch・mug・towel・sticker（240×240、すき通し）：グッズの切り絵シール。Canva の AI の絵（作業用デザイン DAHZeV0i0lw の1ページ目、元の絵 MAHZefIRq8E）から切りぬいた
- frame-11.webp（800×800）：11月の額（紅葉・リボン・お花）。同じデザインの2ページ目（元の絵 MAHZee88Oo0）
- 季節の額は frame-<月>.webp（1〜12）と frame-birthday.webp（800×800）。まん中と外側はすき通し（10/31 しょーくん「額が台紙の上に来る方がいい」。マスの台紙の上に額を重ね、誕生日の額の灰色の背景もなくした）。Canva の AI の絵を作業用デザイン DAHZeV0i0lw の3ページ目から（1月・2月・…の順。1600×1600 のページに入れて PNG で書き出し、800×800・WebP の質78に縮めた）。すき通しは cut-frame.py（Python と Pillow。`python3 cut-frame.py 元の絵 できた絵`）で、ふちとまん中からつながった明るい灰色・白を消している。月見団子のような白い物は色の差で残るが、新しい額を作ったら緑の上に置いて消えすぎていないか見る
