# YouTube のロゴ

youtube-logo.svg は、Google のサーバーにある YouTube の公式ロゴ（フルカラー・明るい背景用）を、1バイトも変えずに置いたもの。

- 取ってきた場所：https://www.gstatic.com/youtube/img/branding/youtubelogo/svg/youtubelogo.svg（2026-10-22）
- 使い方は YouTube のブランドガイドライン（https://developers.google.com/youtube/terms/branding-guidelines）に合わせる：色・形を変えない、白い背景に置く、押すと YouTube（公式チャンネル）へ行く、ページでいちばん目立つものにしない
- 推し手帳は YouTube がなくても成り立つので「developed with YouTube」ではなく、ふつうの YouTube ロゴ
