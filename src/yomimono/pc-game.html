推奨環境と最低環境の見方

公式の表には、OS・CPU・メモリ・グラフィック・空き容量が並びます。最低と推奨の2つに分かれた表が多く、マインクラフトの Java版の案内では、最低は1080pで30FPS、推奨は1080pで60FPSで遊ぶときのめやすとされています。

表の分け方も作品でちがいます。ウマ娘の DMM GAMES版の表は「動作環境」の1つだけで、メモリは8GB以上、空き容量は20GB以上です。刀剣乱舞ONLINEの表はメモリが4GB以上で、推奨メモリが8GB以上と書かれています。

マインクラフトの Java版は、2026年7月21日の案内で、推奨のシステム要件が7月21日に変わるとされています。この案内と販売のページの表では、メモリの推奨は16GBで、最低はグラフィックが別についていれば8GB、CPUに入ったグラフィックなら12GBです。統合版は最低4GB・推奨8GBで、Java版とは別の表になっています。

自分のPCのメモリと空き容量を調べる

Windows 11 では、設定の画面でメモリとCPUの名前を確かめられます。マイクロソフトの説明にある順番は、次のとおりです。

  1. 1．スタートを右クリック

    出てきた一覧から「設定」を選びます。

  2. 2．「システム」の「バージョン情報」

    「デバイスの仕様」に、プロセッサとインストールされているRAMの量が出ます。

  3. 3．「システム」の「ストレージ」

    ドライブの使われ方が出ます。ほかのドライブは「ストレージの詳細設定」から見られます。

同じバージョン情報の画面で、Windows が32ビットか64ビットかもわかります。刀剣乱舞ONLINE や ドラクエXI S の表は、64bitの Windows を前提にしています。

公式の表とくらべる

作品を選び、調べたメモリと空き容量を入れると、公式の表の数字にとどいているかが出ます。

くらべているのはメモリと空き容量の数字だけです。表が1つだけの作品は、その表の数字とくらべています。CPUとグラフィックは、この道具ではくらべていません。表の名前と見くらべます。

Windows の版

ウマ娘と刀剣乱舞ONLINE の表は Windows 11 です。マインクラフトの Java版は最低が Windows 10 の64-bit、推奨が Windows 11 の64-bit で、統合版は Windows 10 のバージョン19041.0以上です。

マイクロソフトの案内では、Windows 10 のサポートは2025年10月14日に終わり、その日からセキュリティ更新プログラムを受け取れなくなりました。Windows 11 に上げられるかは、PC正常性チェック アプリかシステム要件で確かめると書かれています。

Windows 11 のシステム要件には、4GBのRAM、64GB以上のストレージ、TPM 2.0 などが並びます。CPUは、マイクロソフトの承認済みの一覧にあるものとされています。

中古のPCを選ぶときに見る所

中古のPCは、商品のページに書かれたメモリ・CPU・グラフィック・ストレージを、遊びたい作品の公式の表と1つずつくらべます。

Windows 10 のPCは、サポートが終わっています。Windows 11 が入っているか、入れられるかを、上のシステム要件で確かめます。ウマ娘の表には、空き容量のとなりに SSD環境推奨と書かれています。ストレージの種類と空き容量も見ます。

国民生活センターの案内では、通信販売には法律上のクーリング・オフ制度はないとされています。返品できるかは店の特約に従い、特約がないときは受け取った日を含めて8日以内なら送料を負担して返品できるとされています。返品の条件は、買う前に店の案内で確かめます。届いたら、すぐに中身を確かめます。

スマホ版とのデータ連携

ウマ娘の DMM GAMES版の公式サイトでは、スマートフォン版とデータを連携して遊べるとされています。連携のあとに DMM GAMES版でログインすると、アイテムのプレゼントがあると書かれています。

NIKKE は、PC版の配信の前に、iOS・Android と同じアカウントでログインでき、進み具合や購入したものが共通になると発表されていました。2023年のPC版の紹介の記事では、メールアドレスや外部のアカウントを連携しておかないと、データが失われる可能性があるとされていました。

マインクラフトは、Java版と統合版で一緒に遊べる相手がちがいます。統合版は Windows・Xbox・Nintendo Switch・PS5・スマホと一緒に遊べて、Java版は Windows・Mac・Linux だけです。新しいPCに入れ直すときは、買ったときと同じ Microsoft アカウントでログインするとされています。

マウスとマウスパッド

NIKKE のPC版は、キーボードとマウスでより細かく狙えると紹介されていました。2023年の紹介の記事では、ニケの切りかえは QWER のキー、バーストスキルは1・2・3のキーとされています。

ロジクールのサポートでは、カーソルが飛ぶ原因として、マウスパッドや面の読み取りが挙げられています。ワイヤレスのマウスは、USBレシーバーに近づけ、PCのうしろのポートにあるレシーバーは前のポートに移すとされています。うしろでは本体にさえぎられることがあるためです。

マウスパッドは、手首をのせる台つきのものもあります。バッファローの低反発リストレスト付きのマウスパッドは約200×230mmで、光学式やレーザー式などのマウスに向くとされています。光学系のマウスでは一部対応できない場合があるとも書かれているので、使うマウスの読み取り方と、パッドの商品ページの対応を見くらべます。

コントローラー

コントローラーで遊べるかは、作品と版でちがいます。ドラクエXI S の Steam のページでは、XINPUT のゲームパッドに対応とされています。マインクラフトは、統合版が対応するゲームコントローラーで遊べて、Java版は今のところコントローラーに対応していないとされています。

NIKKE は、2023年のPC版の紹介の記事の時点では、コントローラーに対応していないとされていました。買う前に、遊ぶ作品の公式の案内と、コントローラーの商品ページの対応の表示を見くらべます。

ヘッドセットと音量

WHO と ITU は2025年2月28日に、ゲームをする人の聴力を守るための基準を出しました。ゲーム機・PC・ヘッドホン・ヘッドセットには、調整しやすい音量や、ヘッドホンとスピーカーを切りかえたときに音量を下げる機能を求めています。

ゲームのソフトには、音の種類ごとに音量を変えられることと、大きな音を長い時間聞くと聴力を失うおそれがあるという注意を求めています。ヘッドセットで遊ぶときは、ゲームの中の音量の設定も見ておきます。

長く遊ぶときの休けい

厚生労働省には、仕事で情報機器を使う人向けの指針があります。リーフレットでは、1時間以内を1サイクルにして、サイクルの間に10〜15分の休止、サイクルの中でも1、2回の小休止を入れるとされています。

同じリーフレットでは、ディスプレイは眼から40cm以上はなし、画面の上端は眼の高さまでとされています。遊ぶための決まりではありませんが、PCの前で長く過ごすときの区切り方のめやすになります。
